# filiprastovic.com

## Arwes first
This site is built on the Arwes framework (`@arwes/*` packages). Before implementing any feature, UI component, animation, or effect, first check whether Arwes supports it natively (check `node_modules/@arwes/` and the Arwes docs) and use that. Only write custom code when Arwes has no equivalent, and say so when you do.
